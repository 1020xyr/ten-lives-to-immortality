# AI 视频工作区

本目录用于把已成稿正文转化为 AI 视频试验材料，包括分镜、画面提示词、声音设计、生成记录和验收结果。

## 与小说正文的边界

- 正文、作品圣经与故事大纲仍是小说事实的权威来源。
- 视频为适应时长而进行的删减、合并、构图和临时外观设计，不自动反写小说设定。
- 人物年龄、外貌、服饰等尚未确认的信息，必须在视频文件中标作“临时视觉方案”。确认后才能进入作品圣经。
- 视频不得提前泄露正文尚未揭晓的谜底，也不得为制造刺激改写人物动机。

## 建议工作流

1. 选择一段已经成稿、人物与动作清楚的正文。
2. 先定短片目的和时长，再做节拍表，不直接从长文逐句生成画面。
3. 建立本次试验的临时视觉连续性卡。
4. 按镜头生成素材，记录模型、提示词、种子或参考图。
5. 粗剪后检查人物一致性、空间连续性、动作方向和对白可懂度。
6. 将结果分为“小说问题”“改编问题”“生成模型问题”，避免为了修视频误改小说。
7. 用户确认有效的视觉方案，再单独讨论是否写入作品事实。
