# H 段：石猴出海与万叶告别

本目录用于制作约 90 秒的 AI 短片，计划用 Seedance 2.5 分三次生成，每次 30 秒。

## 文件导航

- `00_导演分析与改编边界.md`：原段落的情绪结构、画面化难点与改编取舍。
- `01_九十秒顺序故事板.md`：0—90 秒逐镜头安排。
- `02_三段三十秒生成提示词.md`：可复制到 Seedance 的三组提示词及素材指代。
- `03_连续性与验收清单.md`：三段衔接、角色一致性和失败重做标准。
- `04_空间圣经与意境设计.md`：固定大青树、林海、孤峰、海岸和大海的位置，并说明正式镜头如何利用空间表达离别。
- `05_灵性表演与物件生命规范.md`：规定石猴、松鼠、海、树、旧石、木筏和叶子怎样以自然动作呈现内心，避免廉价拟人化。
- `图片/`：定调板、三张九宫格故事板及四张衔接锚帧。

## 核心制作原则

1. 三段不是三个独立短片，而是一条连续情绪：决定离开 → 海上分别 → 次日万叶告别。
2. `K30` 同时是第一段尾帧和第二段首帧；`K60` 同时是第二段尾帧和第三段首帧。
3. 九宫格只负责镜头顺序和构图，角色外观与颜色以定调板和独立锚帧为准。
4. 成片对白和旁白后期单独录制；生成阶段主要锁画面表演、环境音和镜头运动。
5. H 段是未来完整短片直接复用的母段；未来 G 段只接到 `K00`，不得重复 H 段对白或事件。
