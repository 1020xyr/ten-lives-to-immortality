# 连续性与验收清单

> 状态：部分字段属于废弃的远距地理方案。角色、毛发、木筏、叶子等通用检查仍有效；空间与锚帧检查暂以 `06_众生位置与九十秒镜头调度.md` 为准，等待重写。

## 一、资产优先级

发生冲突时按以下顺序判断：

1. 独立首尾锚帧决定每段的开头和结尾构图。
2. 角色定调板决定石猴、松鼠、木筏的外形与尺度。
3. 九宫格故事板决定镜头顺序、景别和动作。
4. 文本提示词补充时间、声音、运镜与表演。

九宫格不是色彩和五官的最高依据，避免模型根据小格中模糊的脸重新设计角色。

## 二、四个衔接锚点

### K00：峰顶决定

- 青灰清晨，内陆大青树在左，宽阔林海居中，孤峰和人物在前景，峰脚小湾及外海在右。
- 峰顶石面有一只从左向右掠过的飞鸟影子；只见影子，不见飞鸟本体。
- 影子运动结束的位置带出拿着藤绳与行囊的石猴、刚到来的松鼠，以及山脚小湾中的木筏，这是未来 `G_END` 的运动匹配接口。
- 两者没有争吵或哭泣，石猴也还没有开口。

### K30：没有落下的手

- 松鼠居左前景，石猴居右后景。
- 石猴的手停在两者之间，没有接触。
- 这一帧必须同时适合“想安慰”和“最终收回”两个动作方向。

### K60：峰顶抱尾

- 松鼠独自在左侧峰顶，身体朝右侧大海。
- 木筏已缩成海面上的极小暗点，石猴不可单独辨认。
- 天色仍是白日末段，不提前出现落叶海。

### K90：叶海中的小点

- 高位大全景，松鼠仍可被辨认但不占画面中心大面积。
- 海在右侧，落叶从近景延伸到山谷。
- 不显示具体文字，不让某一片叶子发光成为“正确答案”。

## 三、每次生成后的硬检查

- [ ] 石猴脸形、毛色、身材与资产板一致，没有忽老忽幼。
- [ ] 石猴双手和前臂为正常皮肤与短毛，没有石壳、鳞片、护臂或不明附着物。
- [ ] 猴毛与松鼠毛以整体块面呈现，没有满身硬刺、湿毛束、塑料毛绒或逐根高频毛发。
- [ ] 松鼠体型和尾巴大小一致，没有变成人形或玩偶。
- [ ] 石猴约为松鼠身高三倍，比例未随镜头漂移。
- [ ] 大海始终在右，木筏始终向右远离。
- [ ] 木筏结构未从竹木筏变成船、舟或有帆器具。
- [ ] 第一段末尾的手势能被第二段开头自然接续。
- [ ] 第二段末尾没有提前进入第二天金色落叶景象。
- [ ] 第三段从安静逐渐扩大，不是一开始就满屏叶片。
- [ ] 叶子没有五官、嘴和拟人身体。
- [ ] 情绪有变化：克制不等于无表情，悲伤不等于持续嚎哭。
- [ ] 九宫格边框、格号和说明文字没有进入成片。
- [ ] H 段 0—4 秒只有视觉接力，没有复述 G 段候鸟告别，也没有提前出现离别对白。
- [ ] 大青树根植内陆森林，孤峰独立位于林缘，峰脚小湾属于同一座峰，画面没有凭空增加第二座主峰。
- [ ] 峰顶遗迹是与母岩相连的断裂岩基和不规则岩板，不呈圆壳、蛋壳、碗或核桃形。

## 四、积分有限时的重做优先级

1. **必须重做**：角色换脸、方向反转、首尾帧接不上、木筏消失或变形、第三段无法辨认松鼠。
2. **尽量重做**：情绪完全错误、镜头顺序错乱、叶子长出脸、石猴表现成凯旋英雄。
3. **可以剪辑补救**：某个转场略硬、局部手脚小变形、单个镜头时间过长、环境声不理想。
4. **后期直接处理**：对白、旁白、音乐、部分环境音、颜色轻微不一致。

## 五、建议的试制顺序

先不要立即消耗三次视频积分：

1. 先评审角色定调板和四张锚帧。
2. 再评审三张九宫格，删掉不喜欢的镜头或替换构图。
3. 先生成第三段“万叶告别”，它最能验证整体美术和情感是否成立。
4. 第三段通过后，再生成第二段和第一段；这样能以最终情绪反推前面的色彩与表演。
