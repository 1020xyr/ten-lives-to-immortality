# H 段连续性与验收清单

## 输入资产

- [ ] 只使用 R05、R06、R07 与 H01—H16；旧图不得混入参考。
- [ ] 所有输入为同一 16:9 画幅，无边框、文字、锐化噪声和九宫格分割线。
- [ ] 每张参考图在提示词中明确绑定角色、尺度、场景或关键帧职责。

## 空间与摄影机

- [ ] 巨树紧邻海崖，小湾就在树下，眺望台属于同一根岩体。
- [ ] 海与离开方向始终在右；松鼠在告别段始终位于左侧。
- [ ] H07/H08 构图、地平线和摄影机完全一致，只改变木筏距离与人物动作。
- [ ] H09/H10 构图、光线和摄影机完全一致，只改变远点有无与松鼠姿态。
- [ ] H11/H12 枝干几何和摄影机一致，只改变时间与醒睡状态。
- [ ] 未经明确动机不越轴、不反转行进方向、不增加机位。

## 比例与资产

- [ ] 松鼠身体约为石猴站高五分之一；大尾巴不等于大身体。
- [ ] 木筏约三米长、一点二米宽，结构始终是低平原木筏。
- [ ] 石猴手爪正常，无石壳、核桃壳、鳞片、护臂或不明附着物。
- [ ] 毛发以整体体块运动，不呈硬刺、湿束、塑料绒或高频闪烁。

## 动作与表演

- [ ] 每个动作都有动机、准备、执行、反应和余波；一镜只有一个主要动作。
- [ ] 松鼠在木筏进入中远景之前不离开岸边；H08→H09 才省略到高处。
- [ ] H11—H16 松鼠全程在树枝上，不落到树根、岩石、沙滩或地面。
- [ ] 松鼠跑动为真实四足重心，尾巴是滞后次级动作。
- [ ] 悲伤以抱尾、收肩、耳朵、视线和停顿表达；无明显泪痕。
- [ ] 叶片无黑边、焦黑阴影、贴纸感、五官或统一整齐轨迹。

## 故事与节奏

- [ ] 第一段先建立两者相处，不急于用离别结果覆盖关系。
- [ ] 第二段只有两个主机位，距离变化有足够停留时间。
- [ ] 第三段依次完成醒、听、追、停、挥手；没有多余绕行和机位炫技。
- [ ] 最终大全景让松鼠很小，但仍能辨认其枝端挥手姿态。

## 成片三遍检查

1. 静音播放：动作、空间和情绪是否仍然清楚。
2. 低速／逐帧：脸、手、毛发、木筏、叶子、背景和尺度是否漂移。
3. 只听声音：海浪声桥是否连续，音乐是否过度替画面煽情。

出现空间冲突、动作不可能、角色／道具变形或主事件读不懂时，判为 P0；尺度漂移、越轴、表演方向错误或镜头过密判为 P1。P0/P1 未清零不得付费生成下一版。
