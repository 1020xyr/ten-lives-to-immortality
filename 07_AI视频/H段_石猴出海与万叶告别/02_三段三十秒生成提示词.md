# 三段三十秒 Seedance 生成提示词

## 素材上传约定

每次只上传当前段真正需要的素材，避免模型在过多参考之间摇摆。

- 图片 1：视觉定调与角色资产板。
- 图片 2：当前段九宫格故事板。
- 图片 3：当前段首帧锚点。
- 图片 4：当前段尾帧锚点。
- 第二、三段可额外上传前一段实际视频，明确只参考其末尾的角色、色彩、方位和运动惯性，不照搬完整镜头。

提示词首句必须说明：**图片 2 仅作为从左到右、从上到下的分镜顺序指导，禁止把整张九宫格直接拍进视频，格线和任何标记都不是画面内容。**

## 第一段 0—30 秒：决定离开

```text
制作一段30秒、16:9横屏、中国神话手绘质感的电影动画。图片2仅作为从左到右、从上到下的分镜顺序指导，禁止把整张九宫格、格线或标记拍进视频。石猴和松鼠的外形、体型比例、服装与色彩严格参考图片1；开场构图参考图片3，结尾必须自然到达图片4。

0-4秒：这是预留给未来完整短片的无对白衔接镜头。一只飞鸟的影子从左上向右掠过湿沙，延续前段候鸟离开的运动方向；影子离开后，镜头发现地上的藤绳和石猴收绳的手，再带出山在左、大海在右、岸边简陋木筏。不要直接出现飞鸟本体，不复述候鸟告别。
4-10秒：切石猴背面中景，他收紧藤绳后停下，松鼠从后方走近。石猴低声告诉她自己要离开；切松鼠近景，她看到木筏后，原本自然的神情一点点僵住，不夸张哭泣。
10-18秒：双人中景。松鼠跳上石头与石猴接近平视，她想装作早已知道，却明显在等他改口。石猴先看向海，再看向她，说明自己不愿永远接受分别和失去。
18-23秒：松鼠视线短暂扫过空鸟巢与无人石台，再回到石猴脸上，暗示此前已有朋友离去，不进入回忆特效。
23-27秒：石猴说要去寻找一种跨越界限的力量。语气坚定但不是英雄宣言，他仍对松鼠不舍。
27-30秒：松鼠轻声说，自己喜欢的都在离开。石猴伸手想碰她的头，手停在半空。画面准确停在尾帧参考构图。

镜头稳定克制，角色表演自然细微，海风吹动毛发和叶片。环境声有海浪、绳索、木筏摩擦；音乐只用很轻的木质拨弦。禁止夸张仙术、禁止胜利式启航、禁止角色突然换脸换毛色、禁止大眼萌系、禁止真人套装、禁止字幕、禁止水印。
本段是未来完整短片直接复用的母段：不要添加“此前候鸟已经离开”的解释对白，不要让石猴在0-4秒提前说话，正式离别内容只能从4秒后开始。
```

## 第二段 30—60 秒：木筏远去

```text
制作一段30秒、16:9横屏、承接上一段的中国神话手绘电影动画。图片2仅作为从左到右、从上到下的分镜顺序指导，禁止把九宫格、格线或标记拍进视频。人物和木筏严格参考图片1；开头精确承接图片3或上一段最后一帧，结尾必须到达图片4。山岸在左，大海在右，木筏全程从左向右远离，禁止方向反转。

0-4秒：承接石猴悬在半空的手。他最终收回手，转身把木筏推入水中，松鼠没有立刻跟上。
4-9秒：低机位看湿沙与浪花，木筏进入海水，石猴撑篙，松鼠追到水边又被浪逼退一步。
9-14秒：从木筏反打岸边，石猴回头一次，看见松鼠越来越小。他握紧竹篙，没有挥手，继续向右离岸。
14-20秒：切回岸上跟拍。松鼠忽然沿山径奔跑，越过石块和低枝，动作急而不滑稽，呼吸越来越乱。
20-24秒：她冲上曾经看见大海的高峰。镜头从她身后推向海面，木筏已经只是远处黑点。
24-27秒：松鼠朝海面喊，为什么要走得这么急。切石猴背影，他肩膀轻轻一动，似乎听见，却没有回头。
27-29秒：极远景，木筏黑点没入海上强光，音乐与环境声短暂抽空。
29-30秒：切松鼠近景，她抱紧自己的大尾巴蹲下，一滴泪落在毛上，停在尾帧构图。

声音突出木材入水、桨声、奔跑喘息、山顶风声；对白少，音乐不煽情。禁止木筏变形、禁止海陆左右关系改变、禁止石猴突然站成英雄姿势、禁止松鼠拟人成人类少女、禁止字幕和水印。
```

## 第三段 60—90 秒：万叶告别

```text
制作一段30秒、16:9横屏、承接上一段的中国神话手绘电影动画。图片2仅作为从左到右、从上到下的顺序故事板，禁止把整张故事板、格线或标记拍进视频。松鼠外形严格参考图片1；开头从图片3或上一段最后一帧自然转场，结尾到达图片4。大海仍在右侧远方，空间方向不可改变。

0-4秒：承接峰顶抱尾哭泣的松鼠，以自然溶接表现夜色掠过，她回到树洞里蜷着睡去，不做快速时间机器特效。
4-8秒：清晨，树洞近景。松鼠睁眼，先是耳朵动了动。平日应有的鸟翼声和猴群声全部消失，只剩很远的海浪。
8-12秒：镜头跟随她走出树洞。山林与海面都被秋晨染成灰金和金黄，安静得反常。
12-16秒：一片完整的金色叶子逆着其他落叶缓慢靠近她，在近处轻轻旋转，传来一句很轻的告别。
16-20秒：松鼠急忙转身，追问声音是谁、在哪里。她不是哲理式沉静，而是真的怕再次失去。
20-24秒：主观镜头里，那片叶子一度清晰，却被越来越多的叶片遮住。声音从不同方向回答，松鼠原地转圈寻找。
24-27秒：镜头绕松鼠半圈后升高，落叶从几十片变成铺满山谷的叶海，她仍试图分辨其中一片。
27-30秒：镜头持续拉远，松鼠成为金色叶海中央很小的身影，右侧远方是发亮的大海。许多轻声从四面叠起，请求不要忘记它们曾经存在。最后不出现文字，停在大全景。

声音设计从近乎绝对安静开始，逐渐加入单片叶摩擦声，再扩展为满山沙响与多方向轻声。叶片没有脸、嘴或眼睛；不要恐怖鬼声，不要金色魔法粒子，不要神圣升天效果，不要角色换色，不要字幕和水印。
```
