# 角色与场景参考图提示词

状态：初版、待生成、待品鉴。所有人物外观都是本次影像试验的临时方案，不属于已确认小说事实。

## 生成顺序

1. 先生成江眠角色板；用户确认后，将其中一张正面图作为后续人物图的风格参考。
2. 再生成周成、孙师兄，并用江眠角色板约束整体写实程度、服装阶层和色彩。
3. 再生成外院、饭堂、练功地。
4. 最后生成道具板和 16 格分镜图。

每次只解决一种资产。不要把“人物 + 场景 + 动作 + 剧情”塞进同一张设定图。

## I01｜江眠角色板

```text
中国传统仙侠长篇的写实影视角色设定板，同一个年轻男性外院弟子“江眠”的四视图：正面胸像、左侧面、右侧面、自然站立全身。清瘦但不病弱，长期做基础练习形成的自然体态；黑发简单束起，几缕短发自然落下；五官耐看、不过分精致，眼神平静但并不木讷，观察物品时会自然集中注意力。穿洗旧的灰青色短袍、粗布内衫、普通布腰带和旧黑布鞋，腰间挂三尺灰绿色旧青藤索、灰布钱袋和磨损木饭牌。衣物有真实褶皱、洗旧色差和小范围修补痕迹，没有破烂乞丐感。

中性浅灰背景，柔和自然光，85mm人物摄影质感，正常人体比例，真实皮肤和布料，角色设计信息清晰，不摆战斗姿势，不持剑，不施法。四个视图必须是同一张脸、同一发型、同一套服装和同一道具位置。

避免：明星脸，网红妆，柔弱书生，冷酷杀手，夸张忧郁，白衣飘飘，玉冠，华服，铠甲，发光配饰，日式或韩式古装，现代拉链，游戏角色选择界面，动漫风，多余手指，文字乱码，水印。
```

## I02｜周成角色板

```text
沿用江眠角色板的写实国风仙侠影视美术，同一个年轻男性外院弟子“周成”的正面胸像、三分之二侧面和自然站立全身。与江眠年龄层接近，但神态更外露、动作更快；不是油滑奸商，也不是搞笑丑角。黑发束起，面部轮廓与江眠明显不同。穿褐色洗旧短袍，袖口因采晨露而扎紧，腰间挂数只细口白瓷瓶和一只小布包。姿态像刚要把自己发现的新东西展示给熟人，带一点确信和得意。

中性浅灰背景，自然柔光，真实皮肤、粗布和瓷器材质，正常人体比例。所有视图保持同一张脸、服装与瓷瓶位置。

避免：猥琐，坏人脸，夸张奸笑，滑稽表情，富家公子，华服玉佩，现代物件，动漫风，文字和水印。
```

## I03｜孙师兄角色板

```text
写实国风仙侠影视角色设定板，一名比江眠稍年长的宗门饭堂执事弟子“孙师兄”，正面半身、侧面和灶边自然站姿。深色耐脏短袍，外系洗旧布围裙，袖子挽起，手上有长期洗锅和添柴留下的轻微粗糙感。神情忙碌、讲规矩，对江眠是熟人式不耐烦，不凶恶、不慈祥说教。真实普通人的脸，体格结实但不魁梧。

自然柔光，真实皮肤和布料，角色板背景干净。保持三视图同一张脸和服装。

避免：酒楼掌柜，肥胖喜剧形象，凶狠监工，仙风道骨长老，华服，盔甲，夸张表情，动漫风，文字和水印。
```

## I04｜青梧宗外院环境板

```text
写实国风仙侠电影的场景概念图，一座位于山中的传统修仙宗门外院生活区，不是主殿和旅游景区。旧青瓦木屋沿缓坡分布，中间有磨损石阶和公共水槽，墙根晾着布袜和普通弟子衣物，竹林从屋后生长，远处只能看见一小段更高的山峰与云雾。清晨，薄雾、冷青自然光，院中已有弟子洗漱和匆忙赶路，但人物只是环境比例参照。建筑维护尚可但有长期使用痕迹，排水沟、木门、石苔和生活杂物合理。

24mm广角，平视机位，空间关系清楚，真实木石纹理，低饱和青灰与褐色。不要宏大宫殿、悬浮山峰、瀑布云海中心构图、遍地发光法阵、仙气宣传画、现代建筑、日式神社、文字和水印。
```

## I05｜外院饭堂环境板

```text
写实国风仙侠宗门的普通外院饭堂，空间不大，数张磨损木桌，面向院子的成排木窗，其中最后一扇可以上下或左右合拢；后方是烧柴灶台、一口有使用痕迹的大铁锅、木桶、碗架和萝卜小碟。早课开始后人已不多，灶火暖光与窗外冷晨光交汇，空气中只有适量蒸汽。这里给低阶弟子供应简单早饭，不是豪华酒楼，也不是脏乱贫民窟。

28mm电影场景摄影，平视，清楚展示木窗—木桌—灶台的空间方向，真实木材、铁锅、陶碗与柴火材质。不要宫殿大堂、红灯笼酒楼、丰盛宴席、过量烟雾、神光、现代厨房、文字和水印。
```

## I06｜竹林练功地环境板

```text
写实国风仙侠外院后坡的一小块简陋练功地，三面疏竹，一块可坐的灰石，一根布满藤索、剑痕和长期撞击痕迹的木桩，木桩右侧有一根位置固定的低垂竹枝。上午自然日光从竹叶间落下，地面是压实泥土、碎叶和少量石子。没有擂台、观众席、法阵和华丽武器架。这只是普通外院弟子自行练习的安静角落。

35mm镜头，平视中景，画面左侧留人物站位，木桩位于右侧，明确保留藤索从左向右运动的空间。低饱和、真实材质、自然风。不要浓雾、仙气光柱、宏大竹海、武侠决战气氛、文字和水印。
```

## I07｜关键道具板

```text
写实国风仙侠影视道具设定板，干净中性背景上分区陈列五类低阶修士日用品：一，十八枚小型旧铜色灵钱，方圆造型，边缘磨损，表面只有很淡的灵纹，不发强光；二，一只手掌大的灰布抽绳钱袋，有多次缝补；三，一条三尺长灰绿色旧青藤索，边缘起毛刺，能够弯曲缠绕；四，一块磨损木饭牌，打孔穿细绳；五，三张赤黄色旧符纸和折三层的油纸包，符纸上是鲜红但不发光的不规则朱纹。

俯拍与局部侧视结合，真实尺寸比例、材质和旧损清楚，影视道具摄影，柔和侧光。不要宝物光效、漂浮、黑气、复杂中文标签、现代硬币、塑料、游戏图标、文字和水印。
```
