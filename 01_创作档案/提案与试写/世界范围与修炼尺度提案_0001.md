# 世界范围与修炼尺度提案 0001｜由近及远

## 状态

提案，等待用户评审。本文只规定不同篇幅阶段需要看见多大的世界，不提前补齐所有国家、宗门和地名。

## 世界展开原则

1. 世界不是在换地图时才突然生成。青梧宗会通过商货、来客、旧史和人物出身提前显示它位于更大的地域中。
2. 每扩大一层范围，先让读者认识一个具体地方和生活在那里的人，再讲这一层的势力格局。
3. 新地域必须改变人物能做什么、需要什么和会失去什么，不能只是把灵钱改成更大的货币、把敌人境界抬高。
4. 离开故地不等于故地停止运转。周成、魏执事、严老等留守或阶段离场人物仍有自己的变化。
5. 远期名称均暂缓。近一百章只命名真正要进入场景的地点。

## 六层世界尺度

### 第一层｜山门生活圈｜约第 1—100 章

- 场景：青梧宗外院、照雪峰、曲河坊、东崖、鹿门集、邻近山道与小型遗址。
- 社会：外院弟子、内门诸峰、坊市散修、商贩、驭风舟、普通修仙劳务。
- 读者应获得的认识：低阶修士如何吃饭、挣钱、修炼、养伤、买卖、结伴和承担宗门规矩。
- 叙事限制：不解释整个天下；青梧宗内部也只展开与当前故事有关的部分。

### 第二层｜一州修仙圈｜约第 101—400 章

- 场景：青梧宗所在州域、郡城、修士家族、邻宗、边境山地和地方王朝机构。
- 社会：宗门不再是唯一秩序，家族、官府、商会、散修盟与异族各有规则。
- 读者应获得的认识：青梧宗在一州只是有分量但并非统治一切的宗门；不同修士道路有真实利益差异。
- 叙事功能：让第三、第四名命契者拥有与江眠完全不同的生活根基。

### 第三层｜诸州与内海｜约第 401—900 章

- 场景：多州大陆、古战场、内海、岛宗、妖族领地和跨州商路。
- 社会：大型宗门与区域联盟能够发动战争或封锁资源，但仍不能控制全部边缘地带。
- 读者应获得的认识：传统仙侠世界的地域、族群、传承和生活方式真正多样化。
- 叙事功能：十命者从零散个体逐渐成为多个势力争夺或忌惮的对象。

### 第四层｜九域与登天遗址｜约第 901—1200 章

- 场景：世界核心诸域、远古登天遗址、破碎小界和天外通路。
- 社会：关于成仙的历史证据、失败道路与利益集团进入现实冲突。
- 读者应获得的认识：成仙并非只要修为足够便自然发生；道路曾被具体人物和组织改变。
- 叙事功能：全书中点后把十命实验放进更大的历史，但仍由人物行动推动。

### 第五层｜仙道文明｜约第 1201—1700 章

- 场景：上界边缘、仙道宗派、多个小界及制造命契的旧址。
- 社会：仙人不是抽象神明，而是有等级、资源、派别、家庭、恐惧和利益的人。
- 读者应获得的认识：更高世界不必然更高尚，长生也没有自动解决人的问题。
- 叙事功能：具体揭开造命者、工具、过程、受害者与既得利益者。

### 第六层｜诸界终局｜约第 1701—2000 章

- 场景：天门、命契核心地点、受其影响的诸界和战后归处。
- 社会：前期各地建立的关系与势力以自己的选择参与或退出，不临时召唤陌生大军完成终局。
- 叙事功能：把真相变成现实行动和代价，完成成仙、分命及人物归处。

## 修炼尺度建议

境界名称和本质仍待专门确认；这里只给出节奏上限，防止升级过密或两千章原地踏步。

| 篇幅 | 建议主境界范围 | 故事要求 |
| --- | --- | --- |
| 1—100 | 炼气前中段 | 先学会控制身体、武器和基础术法，不靠境界碾压解决异常。 |
| 101—300 | 炼气中后段至筑基 | 筑基必须改变江眠的行动权限、寿命认知和命契感知。 |
| 301—600 | 筑基至金丹 | 金丹劫第一次实质波及其他命契者。 |
| 601—900 | 金丹至元婴 | 元婴阶段扩大远行与神魂层面的能力，同时增加被追踪风险。 |
| 901—1200 | 元婴至化神 | 能够跨域、入小界，开始直接触碰登天遗址。 |
| 1201—1500 | 化神以上的中高阶 | 具体境界待世界规则成熟后再命名，避免现在堆词。 |
| 1501—1800 | 接近此界顶点 | 突破与拆契、天门和人物选择互相影响。 |
| 1801—2000 | 成仙前后 | 每次力量变化服务终局行动，保留战后生活。 |

## 近百章资源与战力边界

- 江眠目前炼气三层，不因半招获得稳定越阶能力。
- “截雨”只能在特定共鸣与危险下出现，且可能伤及自己或旁人；不能成为常规必杀技。
- 第十一至第四十章重点是学会收势、判断何时不出剑，而不是连续获得新招。
- 顾清荷的姓名已经确认；若采用照雪峰剑修身份，境界建议在炼气六至七层，明显强于江眠，但不是可以处理所有危险的保姆。
- 陈渡的正式境界继续暂缓；他失踪的威胁不能仅靠修为数字制造。
- 灵钱继续承担真实约束：路费、药费、兵器和误工都要有人支付，但不能每个故事都写成挣钱任务。

## 暂不回答的问题

- 世界最终是大陆、星辰还是多界结构，以进入相关篇幅时的故事需要决定。
- 完整境界表、每境寿命与绝对战力差暂不一次写死。
- 天门为何关闭、造命者是谁、十命是否能够全部保留，均属于中后期答案。
- 顾清荷的照雪峰身份、境界与首次登场位置仍待确认，姓名不再是候选项。
