# 时间线

月份与年份尚未命名，以下以正文开篇当月记日。

| 日期 | 章节 | 事件 |
| --- | --- | --- |
| 初一 | 第 1—2 章 | 江眠尚差六枚灵钱买养气散；周成提出试符委托；两人查符并约定后日下午在西坪试验。 |
| 初二 | 第 3 章前半 | 周成继续查符；江眠照常练索、替人看步法。 |
| 初三 | 第 3—4 章 | 西坪第一次催符；剑鸣并偏向江眠；严老确认符是重新着色的旧符。 |
| 初四 | 第 5 章 | 两人第一次去曲河坊退符未果；江眠买到养气散；得知葛三槐初八可能再来。 |
| 初四夜至初八晨 | 第 6 章 | 江眠分三次服药，右腕短暂发热，晋入炼气三层。 |
| 初八 | 第 7—9 章 | 曲河坊退符纠纷；第二柄符剑失控；江眠第一次使出半招并伤腕；坊务堂处理赔偿；流言传回外院。 |
| 初八夜 | 第 10 章前半 | 经舍核验；白掌柜判断半招疑似陈渡的“截雨”。 |
| 初九清晨 | 第 10 章结尾 | 照雪峰回信确认陈渡未归，次日派人验剑。 |
| 初十至十六 | 第 11—15 章 | 首次低风险核验；江眠留在外院定期复核；《截雨半式》流传并导致模仿受伤；江眠养伤、看场并开始基础控气练习。 |
| 初十七起 | 第 16—19 章 | 江眠第三次换药后上照雪峰；学习停剑，了解陈渡普通生活与被改清册；确认杜衡线索指向鹿门集。 |
| 初二十余至二十八 | 第 20—22 章 | 江眠、顾清禾、韩竞与周成下山；经青石驿抵达鹿门集；发现白羽旧印回收是诱饵，并收到北坡废窑邀约。具体出发日需后续统一校准。 |
| 初二十八午后至夜 | 第 23—31 章 | 众人进入北坡废窑；遭遇罗横引剑阵；江眠第一次主动停住陌生半招；取得杜衡证词与青铜残片；鹿门集巡守接手人犯，当夜在南街处理伤势与口供。 |
| 初二十九起数日 | 第 32—34 章 | 经青石驿回宗；残片移入照雪峰验剑堂封存；江眠取得核验知情权与有期限的行动安排。具体跨月日期待月份命名后统一。 |
| 回宗后约十日内 | 第 35—40 章 | 江眠开始基础学剑；顾清禾参加峰内小比；第三次核验确认残片为两个独立位置；夜间银线短暂指向西北，封剑谷进入下一步准备。 |
