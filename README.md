# 十命成仙

人与 AI 长期共创的传统仙侠网络小说项目。

## 项目结构

- `01_创作档案/`：原始口述、讨论、决策、提案与试写。
- `02_作品圣经/`：已经确认、跨章节长期有效的作品事实。
- `03_故事大纲/`：总纲、分卷大纲与章纲。
- `04_正文/`：确认后的正式正文，一章一文件。
- `05_连续性校验/`：时间线、人物状态、伏笔与变更记录。
- `06_发布稿/`：从确认正文汇编出的发布版本。
- `07_AI视频/`：网文影像化试验的分镜、提示词、生成记录与验收材料；不自动成为作品事实。

当前处于世界设定、两千章总纲与前三章试写阶段。项目协作规则见 `AGENTS.md`。
